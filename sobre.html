O que é Esquizoides Story?

Esquizoides Story é um projeto criado para representar um universo de histórias, personagens, produtos e experiências.

O principal objetivo é desenvolver uma identidade própria para o projeto, permitindo que diferentes histórias sejam apresentadas dentro de um mesmo universo.

Imagem do universo

Esta imagem faz parte da identidade visual utilizada para representar o universo do projeto.

Como tudo começou?

Tudo começou com uma ideia simples: criar histórias capazes de despertar a curiosidade das pessoas.

A partir dessa ideia surgiram personagens, aventuras, produtos e diferentes possibilidades para expandir o universo.

Características do universo

  • Personagens únicos
  • Histórias independentes
  • Mistérios e aventuras
  • Produtos temáticos
  • Projetos criativos
  • Interação com o público

Nossos objetivos

  1. Criar histórias interessantes.
  2. Desenvolver personagens marcantes.
  3. Criar produtos relacionados ao universo.
  4. Desenvolver novos projetos.
  5. Criar experiências para o público.
